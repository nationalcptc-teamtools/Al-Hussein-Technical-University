# Security Resources

- **[Payloads All The Things](https://swisskyrepo.github.io/PayloadsAllTheThings/)** — A huge collection of payloads and bypasses for web application security testing.
- **[Internal All The Things](https://swisskyrepo.github.io/InternalAllTheThings/)** — Cheat sheets for internal network pentesting, Active Directory, and red team operations.
- **[HackTricks](https://hacktricks.wiki/)** — A massive wiki of pentesting techniques and tricks covering almost every technology and attack surface.
- **[OT Notes](https://ot.null-security.com/index.html)** — Training notes and labs on Operational Technology (OT/ICS) security, from Modbus attacks to detection.
- **[The Hacker Recipes](https://www.thehacker.recipes/)** — Clear, methodology-focused guides for offensive security, especially Active Directory attacks.
- **[Reverse Shell Generator](https://www.revshells.com/)** — An online tool that generates ready-to-use reverse shell commands for many languages and listeners.
- **[Scrub Log](https://scrublog.com/)** — Personal security blog and notes.
